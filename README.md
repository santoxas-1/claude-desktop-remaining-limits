# Отображение остатка лимитов в Claude Desktop

[![Claude Desktop](https://img.shields.io/badge/Claude%20Desktop-Compatible-orange?logo=anthropic)](https://claude.ai/download)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-blue)](#)
[![License](https://img.shields.io/badge/License-MIT-purple)](#)

Мод для официального приложения **Claude Desktop**, добавляющий аккуратный нативный индикатор остатка лимитов модели непосредственно в рабочую область — **слева от выбора модели**.

---

## Что делает этот мод

1. **Всегда показывает актуальный остаток:**
   - Выводятся ровно два значения: `5h __%| 7d __%` (например, `5h 92%| 7d 100%`).
   - На индикаторе зафиксирован расчет оставшихся процентов.

2. **Всплывающее окно строго по клику:**
   - По умолчанию окно скрыто и не перегружает интерфейс.
   - Открывается **только при нажатии** на индикатор.
   - Никаких назойливых всплывающих подсказок при наведении курсора.
   - Закрывается по повторному клику, клику в свободную область или по клавише `Escape`.

3. **100% нативный дизайн Claude Design System (CDS):**
   - Цвет текста и оформление кнопки в точности повторяют кнопку **«+»** (добавить контент) и кнопку **«Автоматически»** (Ctrl+Shift+M).
   - Цвет фона всплывающего окна на 100% совпадает с нативным окном уровня рассуждений:
     `var(--cds-surface-popover, var(--cds-surface-3, #282726))` с эффектом матового стекла `backdrop-filter: blur(20px)` и скруглением 10px.

4. **Интеллектуальная поддержка моделей и шлюзов:**
   - **Gemini / Google Antigravity:** отображаются реальные скользящие квоты сессии и недели активного аккаунта, а также время сброса.
   - **Модели через API (Claude Fable, Claude Opus, GPT Astra, Sol, Luna, DeepSeek):** автоматически распознаются как API-модели — индикатор выводит `5h ∞ | 7d ∞`, а в окне отображается карточка:
     > **Подключение через API**  
     > *Модель работает через API-шлюз. Скользящие 5-часовые и недельные ограничения сессии не применяются (без ограничений).*
   - **Мгновенный учет переключения аккаунтов:** при смене активного профиля в шлюзе OpenCodex лимиты мгновенно обновляются под новый аккаунт.

5. **Молниеносная кнопка «Обновить данные»:**
   - Мгновенный отклик с первого же клика (0 мс задержки на касание).
   - Быстрый красивый оборот стрелочек и надпись `✓ Обновлено!`.

## Установка

### Windows (в 1 клик)
1. Скачайте архив репозитория (кнопка **Code → Download ZIP**).
2. Распакуйте архив в удобное место.
3. Запустите файл **`install.bat`** двойным кликом мыши.
4. Перезапустите Claude Desktop.

### macOS / Linux
Откройте терминал в папке проекта и выполните:
```bash
chmod +x install.sh
./install.sh
```
После завершения перезапустите Claude.

---

## Обновление

Если приложение Claude Desktop автоматически обновилось и сбросило модификации:
- **Windows:** запустите **`update.bat`** — скрипт восстановит работу мода за 1 секунду.
- **macOS / Linux:** выполните `./update.sh`.

---

## Удаление

Мод удаляется чисто, без следов, с полным восстановлением оригинального `index.html`:
- **Windows:** запустите **`uninstall.bat`**.
- **macOS / Linux:** выполните `./uninstall.sh`.
